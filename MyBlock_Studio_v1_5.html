Extension Exporter
PenguinMod custom extension

      
MyBlock Studio tự tạo getInfo(), block definitions, opcode handlers và đăng ký extension. Các opcode Motion, Looks, Sound, Operators, Variables/Lists và Pen đã nhận diện sẽ gọi primitive của PenguinMod; Pen cần được nạp trong runtime.

      
Đang chờ biên dịch.

      
Chưa có extension.

      

      
My Blocks có đánh dấu Returns a value sẽ được xuất thành reporter/boolean reporter; block Return sẽ cung cấp giá trị. Có thể ghép reporter My Block vào input của My Block khác.\nCách nạp: PenguinMod → Extensions → Load Custom Extension → Local File (chọn tệp .js), hoặc JavaScript Text (dán toàn bộ mã extension). MyBlock Studio v1.5 có fallback JavaScript cho các phép toán/so sánh/logic thuần, nên Boolean Reporter vẫn xem trước được ngay cả khi PenguinMod không cung cấp runtime hoặc util.target. Công cụ vẫn dùng cầu nối đến các primitive nội bộ của PenguinMod VM nên cần chế độ unsandboxed. Chỉ bật cho extension do chính bạn tạo hoặc thực sự tin tưởng.

      
Cách kiểm tra block có thực sự chạy: Trên Sprite1, tạo script when green flag clicked → M2E kiểm tra runtime → say [Xin chào!], rồi nhấn cờ xanh. Định nghĩa My Block trong project không tự chạy khi extension được nạp; nó phải được gọi từ một script. Khi dùng say/think, nạp extension với tùy chọn Run without sandbox (unsandboxed).
